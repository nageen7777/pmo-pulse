How calculations work

Completion: closed tasks ÷ all tasks.
Cycle time: average calendar days from task start to completion for closed tasks with valid dates.
Scope creep: approved added scope ÷ original baseline scope, using the same unit.
Velocity: closed story points ÷ number of distinct sprints with closed tasks and points.
Duration: inclusive calendar days between planned start and end.

The website calculates automatically after entry or CSV import. Excel formulas calculate inside the downloaded workbook. The site does not read Excel files directly; export each input sheet to CSV.
